# Jstz

:::warning

**The Jstz project is being paused**, due to adjustment of priorities in the Tezos X roadmap, in response to market signals:

*"The absence of strong demand at this stage for a JavaScript interface means that enabling a JavaScript interface (Jstz) in Mainnet is no longer a near-term priority. An important milestone, the RISC-V migration—required to support additional runtimes such as JavaScript—is targeted for H2 2026."*
(see [the full announcement](https://research-development.nomadic-labs.com/tezosx-from-roadmap-to-reality.html#priorities-what-moved-up-what-moved-down)))

:::

Context:

* Jstz (pronounced "justice") is planned to be a JavaScript server runtime for Tezos [Smart Rollups](https://docs.tezos.com/architecture/smart-rollups) with a great developer experience.
With Jstz, one will be able to deploy JavaScript applications known as _smart functions_ that can act as the backend for web applications, including handling logic, storing data, and accepting and distributing payments.

- The Jstz command-line toolkit, sandbox, SDK, and other tools in this repository are 
no longer available for the time being.

In the meantime, you may want to develop dApps and smart contracts on top of [Tezos X](https://x.tezos.com/), either in EVM-targeted languages such as Solidity or in Michelson-targeted languages such as LIGO or SmartPy. Note that EVM and Michelson applications may interact seamlessly in Tezos X using native atomic composability.
